# Licensing

[Documentation index](README.md) · [Contributing](../CONTRIBUTING.md)

Corta's source is licensed under the [Apache License 2.0](../LICENSE). Every
file says so: a source file in a header at its top, every other file in
[`REUSE.toml`](../REUSE.toml). The name, the pangolin mascot and the
application icon are not under Apache-2.0 ([`NOTICE`](../NOTICE)).

One tool enforces this and adds what is missing, and this page is its
reference. The rules themselves are data in
`CortaTerminal/Sources/LicenseHeaders/LicenseHeaders.swift`
(`LicenseHeaders.rules`); when this page and that table disagree, the table
is what runs.

## The header

Exactly this, at the top of the file, followed by one blank line:

<!-- REUSE-IgnoreStart -->

```swift
// Copyright 2026 Noah Qin
//
// Licensed under the Apache License, Version 2.0 (the "License");
// you may not use this file except in compliance with the License.
// You may obtain a copy of the License at
//
//     http://www.apache.org/licenses/LICENSE-2.0
//
// Unless required by applicable law or agreed to in writing, software
// distributed under the License is distributed on an "AS IS" BASIS,
// WITHOUT WARRANTIES OR CONDITIONS OF ANY KIND, either express or implied.
// See the License for the specific language governing permissions and
// limitations under the License.
//
// SPDX-License-Identifier: Apache-2.0
```

<!-- REUSE-IgnoreEnd -->

The middle is the Apache License's own appendix boilerplate, word for word —
including its `http://` URL. Files whose comments start with `#` carry the
same text with `#` in place of `//`. An empty line of the text is the bare
marker (`//` or `#`), with no trailing space.

What is deliberately **not** in it: `©`, "All rights reserved", a year
range, the file's name, or a "Created by" line. Xcode's file template adds
the last two; `fix` removes that template when it adds the header.

### The year

The year is the year the file was **created**, and it never changes:

- Every file that existed when headers were introduced says `2026`.
- A file created in 2027 says `2027` — `fix` writes the current year.
- Editing a file does not bump its year, and a year is never a range
  (`2026-2027`). Nobody re-dates the tree at New Year.

`check` accepts any single four-digit year from 2026 to the current year
and rejects a range, a future year and anything earlier.

### Where it goes

At line 1, with two exceptions that must stay first and keep their line:

| File | First line | Then |
| --- | --- | --- |
| A script with a shebang (`#!/bin/bash`, `#!/usr/bin/env python3`) | the shebang — the kernel reads it from the first two bytes | the header, then a blank line; a Python module docstring comes after that |
| `CortaTerminal/Package.swift` | `// swift-tools-version: 6.2` — SwiftPM reads the manifest's first line | the header, then a blank line |

## Which files carry it

| Files | Treatment |
| --- | --- |
| `*.swift`, `*.metal` | Header, `//` |
| `*.sh`, `*.py`, `*.yml`, `*.yaml`, `*.toml`, `.gitignore`, `.github/CODEOWNERS` | Header, `#` |
| Markdown, `NOTICE`, the Xcode project, storyboards, asset catalogs, `Localizable.xcstrings`, test plans, `Sparkle-Info.plist`, `PrivacyInfo.xcprivacy`, `appcast.xml` | No header — Apache-2.0 by `REUSE.toml`. They either cannot hold a comment or are regenerated by a tool that would drop one |
| Golden fixtures (`CortaTerminal/Tests/CortaTerminalTests/Golden/`), recorded render references (`CortaTests/RenderReferences/`), the fuzz corpus (`CortaTerminal/Tests/Fuzz/`), esctest results (`docs/esctest/`) | **Never** a header: they are test inputs and expectations, and a header would change the bytes under test. Apache-2.0 by `REUSE.toml` |
| `docs/brand/*.png`, `docs/brand/*.gif`, `AppIcon.icon/`, `AppIconDev.icon/` | No header — `LicenseRef-Corta-Brand` by `REUSE.toml`; the terms are [`LICENSES/LicenseRef-Corta-Brand.txt`](../LICENSES/LicenseRef-Corta-Brand.txt), the same as `NOTICE` |
| `Corta/Acknowledgements/Sparkle-LICENSE.txt` | No header — it *is* Sparkle's license (`LicenseRef-Sparkle`), shipped in the app because its terms require the notice to travel with the software. The About window shows it |
| `LICENSE`, `LICENSES/` | License texts; not licensed by a notice |

A file no rule matches is an **error**, not a pass. A new kind of file has
to be classified on purpose: add a rule to `LicenseHeaders.rules` (and to
`REUSE.toml` if it cannot carry a header) in the same pull request, and a
row here.

## The tool

`corta-license`, a SwiftPM executable in the core package. `check` looks
at the files git tracks — what is committed is what the rules are about, and
a release job's archives and unpacked apps in the checkout are not.
`fix` also takes untracked files that are not ignored, so a file created a
moment ago gets its header before it is committed.

```sh
# Report every file that is missing its header, has a non-standard one,
# or matches no rule. Exits non-zero if there is any.
swift run --package-path CortaTerminal corta-license check

# Add the header, with this year, to every file that lacks one.
swift run --package-path CortaTerminal corta-license fix

# Only these files (paths relative to the current directory).
swift run --package-path CortaTerminal corta-license fix Corta/NewThing.swift

# A specific year — only for a file genuinely created in that year.
swift run --package-path CortaTerminal corta-license fix --year 2026
```

`fix` never rewrites a header that is already correct, so running it twice
changes nothing the second time. It never repairs a **malformed** header
either — a year range, an edited line, a header that is not at the top:
whatever is there was put there by hand, so `fix` reports it and leaves it
for a person.

## Where it is enforced

- **Every CI run.** `RepositoryLicenseHeaderTests` (in
  `CortaTerminal/Tests/LicenseHeadersTests`) applies the same rules to every
  tracked file, and `swift test --package-path CortaTerminal` runs it.
- **Every release.** `corta-release-check` runs `corta-license check`
  before it looks at anything else.

`REUSE.toml` follows the [REUSE specification](https://reuse.software/spec-3.3/),
so `reuse lint` can confirm the whole tree independently; CI does not depend
on it.

## Third-party code

Sparkle is the one third-party runtime dependency (D23). Its license and the
notices of the code it bundles are in
`Corta/Acknowledgements/Sparkle-LICENSE.txt`, copied verbatim from the
version `Package.resolved` pins; `AcknowledgementsTests` fails when Sparkle
is updated and the copy is not. Adding a dependency means adding its notice
the same way.
