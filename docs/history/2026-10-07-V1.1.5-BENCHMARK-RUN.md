# The 1.1.5 benchmark run — 2026-10-07

From `main` at `c9432a9` (#257), the tree 1.1.5 is cut from; the D17 build
also carried the release PR's version bump and documentation, no other
code. Since 1.1.1 the render loop changed — #226's theme-derived overlay
colours, #232's opaque canvas and #240's command-status rules drawn in the
Metal pass — so the D17 frame-CPU figure was re-measured under Release
alongside the scripted core run. Machine: MacBook Air, Apple M5; macOS
27.0.1 (26A434); Xcode 27.0 (27A266a), Swift language mode 6, macOS 26.0
deployment target. On battery (74%, discharging), not the mains power §5.2
asks for; ambient load was not controlled. One run of each; observations,
not a controlled comparison. Live rendering, idle CPU, launch,
keypress-to-glass and energy were not re-measured. Summarized in
[Performance §5.6](../PERFORMANCE.md#56-numbers-by-release).
