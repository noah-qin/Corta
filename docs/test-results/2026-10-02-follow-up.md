## Closure boundaries

The historical CoreText exception is mitigated by replacing the CF-keyed
attribute dictionary bridge and removing its forced unwrap. Supported glyph
regressions and bounded input tests validate the new path, but the original
one-off exception has no stable reproducer: its historical root cause is not
proven. Existing symlink rejection is not a concurrent local-filesystem
sandbox. Remote content preflight is not an atomic compare-and-swap.

Modes 0700/0600 are tested on controlled local storage; deployment parent ACLs,
backups and administrator access require separate policy. Stage directories
are storage routing, not HOME/agent isolation. The SSH fixture tests an
independent policy, not the user's private SSH files or external proxy setup.

GUI, extended Instruments/GPU pressure, stable A/B measurements and supported
hardware/OS/font matrix results will be recorded here as they complete.
Full-file/resource/binary coverage remains a separate review requirement;
a passing regression suite is not proof of exhaustive repository audit.

## Extended GPU and Instruments sample

The opt-in four-renderer workload passed 3,715 create/retransmit/evict/close
cycles over 300 seconds; process/per-renderer byte budgets and release to zero
were asserted every cycle. The full image suite passed 12 tests.
Leaks and Allocations were attached to that specific test host for 60 seconds
each. Trace files are retained outside the checkout under `/private/tmp`.
A `leaks` scan at roughly 198 seconds reported 417 nodes / 20,016 bytes in
three NSXPC root cycles to macOS `com.apple.linkd.autoShortcut`; the shown
retaining blocks are AppIntents/Foundation service connection code. The
physical footprint was 180.4 MB. This observed framework/service condition
is not dismissed as a clean leak result, and no all-duration leak claim is made.

Read-only `ssh -G` checks covered the default profile plus one concrete local
alias: StrictHostKeyChecking=ask, ForwardAgent=no, no ProxyCommand/ProxyJump,
no ssh-rsa host-key algorithm, password authentication allowed. `.ssh` is
0700 and known_hosts exists; the app inherits the agent environment. No
private-key contents or agent identity list were collected. Wildcard/include
host enumeration and external authentication policy remain outside this sample.

## Completion pass — 2026-10-02, evening

Picked up from the open list above, in the same worktree and branch.

- **Application TSAN.** Two races, both fixed. `FakeSFTPClient`'s state was
  written by its `async` methods on the cooperative pool while tests read it
  on the main actor; every field is now behind a lock and the fake's own
  appends are atomic (`Guarded`). `TerminalColorPalette`'s live variant —
  several words and an array reference — was written on a settings change
  and read by renderers and by `FrameScheduler`'s display-link callback; it
  is now a `Mutex`, read once per frame into the renderer. Final run with
  `halt_on_error=0` and timeout scale 3: **0 ThreadSanitizer reports**, 749
  passed, 4 skipped, 1 expected failure, 1 failure explained next.
- **The one failure was the developer's own config.** The earlier TSAN abort
  inside `SettingsModelTests.commandHistoryBounds` ran before its `defer`, and
  left `command-history-limit = 0` in `~/Library/Application Support/Corta
  Dev/config`, the file the unit-test host shared with the development
  build. `CommandHistoryHostScopeTests` then saw no records, on `origin/main`
  too. The value was put back to its default (512); the test host now gets a
  throwaway stage per process (`AppPaths`, D22 amended), stale ones are
  pruned at the next launch, and that test `#require`s its wait instead of
  crashing the host on an empty array. Unit plan afterwards: **751 passed,
  0 failed**, 4 skipped, 1 expected failure.
- **UI plan: 14 of 14.** `SplitPaneUITests` passed unchanged. The remote
  workflow test looked for a button named "More"; the menu's label is "More
  actions", and at the browser's opening width it sits in the toolbar's
  overflow menu, so the test now opens it from either place.
- **Leaks.** `leaks` with `MallocStackLogging=1`: the application at 30 s and
  at ~200 s after opening and closing windows, splits, Settings and the SFTP
  preview three times; the test host at 178 s and 216 s into a 240 s run of
  the four-renderer GPU stress (3,713 cycles). **0 leaks in all four.** The
  417-node NSXPC cycle to `com.apple.linkd.autoShortcut` seen once before
  did not recur; its frames were AppIntents/Foundation service code with no
  Corta frame. Not claimed: that no framework ever leaks there.
- **Performance A/B.** Recorded in `PERFORMANCE.md` ("The A/B,
  2026-10-02"): reflow 92.5 → 48.2 ms, non-ASCII-scrollback ASCII search
  450 → 27.5 ms, ASCII search unchanged; the D17 frame figures within each
  other's spread.
