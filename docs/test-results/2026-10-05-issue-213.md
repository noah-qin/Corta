# Issue 213 feedback fixes — 2026-10-05

Source: [issue 213](https://github.com/noah-qin/Corta/issues/213), followed by
the user's reproduction screenshots and Claude Code output.

## Delivered behavior

- Common solid box-drawing borders use cell-aligned strokes. Valid emoji
  presentation sequences such as warning sign + VS16 occupy two cells, with
  right-margin wrapping and insert-mode handling. The supported bases come
  from [Unicode 17 emoji variation sequences](https://www.unicode.org/Public/17.0.0/ucd/emoji/emoji-variation-sequences.txt);
  two-cell presentation is Corta's terminal policy.
- Switching light/dark appearance updates an opaque titlebar and window
  background, including windows in inactive tabs.
- Font zoom keeps the window frame and changes visible rows/columns. Settings,
  keyboard zoom and split panes share this behavior; new panes inherit current
  zoom without persisting temporary zoom to configuration.
- Link hover displays its destination and the Command-click instruction.
  Existing Command-click, optional plain-click and OSC 8 behavior remain.
- Foreground-job close confirmation remains enabled by default. Return now
  selects Cancel.
- The secure-input lock explicitly describes enabled secure keyboard input;
  clicking it opens Privacy & Security settings. It is hidden when disengaged.
- Appearance settings offer three previewable built-in themes alongside
  existing custom themes and their editor.
- Previous/next tab commands have configurable shortcuts, initially
  Shift-Command-[ and Shift-Command-].
- Double-click a tab or choose Rename from its context menu to edit its title
  in the tab bar. Enter saves, Escape cancels, and focus loss saves. Custom
  names survive session restoration. The tab context menu includes New Tab
  and retains available native tab actions.

Transparency/blur, left-side tabs and tab colors were excluded by agreement.

## Screenshot feedback refinement

After the user confirmed the real Claude tables align, follow-up screenshots
identified presentation issues:

- Rename now overlays the native tab title at its center, using a borderless
  text field without a focus ring. The native accessory's trailing placement
  is no longer used. Selection, Enter, Escape and focus-loss behavior remain.
- The toolbar input-source indicator uses one full-height capsule. Its toolbar
  item does not add a second border/background around the smaller badge.
  Prompt placement retains its compact shape.
- Font zoom still changes terminal columns/rows while keeping the frame. The
  temporary columns × rows title now appears only during live window resizing,
  so zoom does not relabel the window and tabs.
- Theme previews use a larger continuous corner radius.

The final app Unit plan passed all 820 tests, with the same 4 recorded known
issues. The UI regression additionally asserts that zoom does not add a size
label, checks rename alignment, and captures the input-source capsule.
UI validation uses an independent application identifier to preserve the user's
running development sessions. An initial fixture-write attempt was rejected by
the UI runner sandbox; the check now enables the indicator through Settings.
