## 准备

使用本次构建的 **CortaDev**，不要用已安装的正式版 Corta。
先在默认主线程模式做下面三组，再对独立线程模式重复。
独立线程仍存在按键上屏延迟回退，人工感觉正常不能替代性能门槛。

打开模式的方法（在另一终端执行，仓库根目录）：

```sh
CORTA_RENDER_THREAD=0 ./script/build_and_run.sh --verify
# 完成一轮后再切换；脚本会关闭同一 checkout 的开发应用。

```

有未保存的命令输入时先处理好；切换模式会重启开发应用。
当前 Codex 启动的开发应用使用临时隔离配置。如果希望沿用该配置，
启动命令还需带同一个 `CORTA_STAGE_DIR`、`ZDOTDIR`；临时目录不适合作为
长期运行配置。下面的功能检查不依赖原有 shell 配置。

## 1. 睡眠与唤醒（约 3 分钟）

1. 在开发应用的一个窗格执行：

   ```sh
   while :; do date '+%H:%M:%S'; sleep 1; done
   ```

   确认每秒出现一行时间。
2. 按 ⌘D 分成两栏，另一栏保持在空闲提示符；设置 → 外观中打开光标闪烁。
3. 点击苹果菜单 → 睡眠。等待约 20–30 秒，再按键盘或触控板唤醒并解锁。
   如果只是关闭了屏幕，未进入系统睡眠，本轮不算睡眠验收。
4. 观察输出在唤醒后是否继续，点击两个窗格并输入；拖动窗口边缘调整大小。
   回到输出窗格按 Ctrl+C，确认输出停止、提示符返回。
5. 回到空闲窗格停 2 秒，确认光标仍闪烁。关闭开发窗口，再开新窗口确认可用。
6. 再做一轮睡眠，第二轮让开发窗口在睡前最小化，唤醒后恢复它。

通过：没有崩溃、黑/白屏、旧画面冻结；时间输出恢复；两个窗格可响应输入、
缩放和关闭；空闲光标恢复闪烁。睡眠期间没有输出是正常的，不要求补齐每一秒。
若恢复窗口后 5 秒仍无画面/输出，或必须重启应用才恢复，记为失败。
只需记录是否异常，无需测精确睡眠时长或更改系统电源设置。

## 2. 真实 IME 输入（约 3 分钟）

先执行 `cat > /dev/null` 并回车。此时输入会显示在终端，但不会被 shell 当成
命令执行；每行提交后丢弃。结束测试先按 Esc 取消尚未提交的组合文字，再 Ctrl+C。

1. 用平时使用的中文输入法输入 `zhongwen ceshi`，选择“中文测试”。观察拼音、
   下划线和候选框；用空格/数字选词，再回车提交整行。
2. 输入一段拼音，在候选出现时用方向键翻候选、退格删拼音；按 Esc 取消一次，
   再重新输入并提交。确认取消后没有残留组合文字。
3. 输入并提交 `中文 English 123`，切换英文/中文输入法，连续输入约 10 秒。
   若平时使用系统表情选择器，补一个表情字符即可，不必新装输入法。
4. 候选框显示时调整窗口大小；按 ⌘D 新建窗格并切换焦点，随后回到原窗格继续
   输入。再用 ⌘T 新建标签页并返回，检查候选和焦点是否恢复正常。
5. 有未提交的拼音时切到另一应用，再切回；确认能继续编辑或明确取消，不出现
   候选框留在别的窗口、文字提交到错误窗格的情况。

通过：候选框靠近实际输入位置；拼音没有被提前送进终端；选词后的字符不丢失、
不重复；Esc/退格和输入法切换有效；候选不会被裁切或留在旧位置；提交不会落到
错误的窗格/标签页。记录“哪一步、哪种输入法、实际现象”，不要求评价细微延迟。

## 3. 光标视觉交接（约 5 分钟）

设置 → 外观 → 光标，依次选择 **Bar / Underline / Block** 并打开闪烁。
每种形状都在空闲提示符停 2 秒，确认会持续闪烁。

一轮：空闲 2 秒 → 输入一个英文字符 → 清空输入（Ctrl+U）→ 再空闲 2 秒。
在提示符执行这一步时不要按回车；Ctrl+U 只清掉尚未提交的命令行。
做 Bar 7 轮、Underline 7 轮、Block 6 轮，共 20 轮。
输入后光标应立即恢复可见，然后在再次空闲时继续闪烁。

补做以下场景，每项观察几秒：

- 空闲时切到另一应用再回来，最小化/恢复窗口。
- ⌘D 分栏，交替点击两栏；⌘T 新建标签页并返回。
- 调整窗口大小，⌘= / ⌘− 改字号，⌘0 恢复字号。
- 输出 `printf '%s\n' '中文 English 🦔 https://example.com'`，拖选文字，
  ⌘F 搜索“中文”，退出搜索，再在链接上悬停。取消选择后回到提示符。
- 打开中文输入法候选框，按 Esc 取消，确认光标重新回到正常闪烁。

通过：始终只有一个属于当前输入位置的光标；无旧位置残影、瞬间双光标、
位置跳动、边缘粗细变化或消失后不恢复。Block 下的文字不能在闪烁时变形、
丢笔画或改变宽度。焦点切换后的光标应对应实际输入窗格。
选择/搜索/链接/Kitty 图片场景当前保守回退到 Metal，不能据此要求它们零应用帧；
这些场景的人工验收只看显示与交接是否正确。
