## Launched-app check (§4.4)

Debug `CortaDev.app` (D22), built into a throwaway derived-data folder and
launched with `SHELL` pointing at a wrapper script, `CORTA_STAGE_DIR` at a
throwaway stage and `CORTA_RESTORE_WINDOWS=0` — all in the launch's own
environment; nothing on the machine changed, and the stage was deleted
afterwards. The wrapper recorded `stty size`, printed `seq 1 100` and
handed over to `bash --norc`.

| # | Check | Result |
| --- | --- | --- |
| 1 | Window size matches columns × rows × point metrics | 860 × 491 points (the window, title bar included) at 120 × 30, the default font and size — the 1.0.1 record measured the same 860-point width |
| 2 | `stty size` in the child agrees | `30 120` |
| 3 | Screenshot: text upright, full size, filling the window | Pass — light theme, the toolbar's SSH and SFTP buttons at the right of the title bar |
| 4 | Output longer than the screen scrolls and uses every row | `seq 1 100` scrolled; 76–100 and the shell's banner filled every row down to the prompt on the last one |
| 5 | Gestures and menu actions reach the pane | Two Return key presses each drew a new prompt. View › Bigger grew the window 860 × 491 → 980 × 521; View › Actual Size restored 860 × 491 |
| 6 | Restored tabbed window | **Not re-run** — tab and restore code changed only in comments and license headers since the [1.0.0 record](2026-09-18-release-checks.md) |
| 7 | Non-English menu bar | Launched with `-AppleLanguages '(zh-Hans)'`: 文件, Shell, 编辑, 显示, 窗口, 帮助 — translated; "Shell" is the same word Apple's Terminal uses there |
