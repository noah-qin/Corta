# 1.1.1 release checks

Date: 2026-10-03. Emergency patch from `fix/empty-enter-marks`, based on
`12b4fe9` (the signed 1.1.0 update-feed commit). Marketing/core version
1.1.1; build counter 6 in all twelve shipping, development and test configurations.

## Automated

- Full terminal core suite: 745 tests in 76 suites passed.
- Full app Unit plan: 779 passed, 4 skipped, 1 expected failure, no unexpected
  failures (784 test cases; dynamic parameters account for additional runs).
- Real PTY/session regression coverage: first prompt, repeated empty Return,
  `true`, `false`, and empty Return after failure; command records and
  success/failure line marks checked. zsh, bash and fish 4.9.2 native and
  `no-mark-prompt` fallback passed locally; unavailable fish paths are optional.
- Original zsh/bash scripts reproduced unsolicited `D;0` on first/empty
  prompts and repeated `D;1` after failure. Fixed scripts emitted only
  `D;0` for `true` and `D;1` for `false`.
- Existing shell-integration renderer tests passed, including no rule for a
  mark without an outcome. Installer/update and documentation tests passed.
- Appcast workflow YAML and all run-block Bash syntax passed; merge logs
  include number, URL, mergeable and mergeStateStatus before `--squash --auto`.

## Launched application

Built and launched CortaDev through `script/build_and_run.sh --verify`.
The user initially reproduced the issue because their installed `.zshrc`
Corta block still contained the old hooks. The block was backed up and
updated, the app relaunched, and the actual login-shell PTY sequence passed.
The user then confirmed the fix and authorized publication of 1.1.1.
Unrelated window, gesture, locale and restore scenarios were not re-run;
this patch changes shell hooks and release automation, not those paths.

## Distribution

Signing, notarization, packaged-app checks and feed publication are enforced
by `release.yml` / `appcast.yml` at v1.1.1. Local tests do not establish those
results. Real fish 3.x was not available; the fallback was exercised in fish
4.9.2. Existing installations need Settings ▸ Terminal ▸ Shell Integration
▸ Update and a new shell to load these corrected hooks.
