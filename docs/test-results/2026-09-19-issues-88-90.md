# Mouse tracking, shared coordinates and toolchain verification

Date: 2026-09-18–19. Base: `7dcfcca` (the initial implementations were
included in #94). This record covers the follow-up changes and the current
acceptance status of #88, #89 and #90.

## Environment

- macOS 27.0 (26A428), Apple silicon.
- Xcode 27.0 (27A266a), Swift 6.4 (`swiftlang-6.4.0.34.1`).
- macOS SDK 27.0 (26A425); Swift language mode 6; deployment macOS 26.0.
- Only `/Applications/Xcode.app` was found in the installed applications.
  Its build is the stable release.

## Automated results

- `swift test --package-path CortaTerminal`: **615 tests, 66 suites passed**.
- App suite: **653 tests, 104 suites passed**, with four expected known
  issues from `MetalRenderTargetTests`' deliberately invalid target fixture.
- Mouse tests cover exact held/unheld motion encoding, mode gating,
  same-cell coalescing and modifier changes during an override gesture.
- Parser tests cover independent tracking/encoding state, switching modes,
  resetting modes, DECRQM and terminal reset.
- Existing viewport, selection, search highlight and image tests passed.
  A range regression verifies both endpoint columns survive shared mapping
  and backwards totals do not move a range.
- Configuration round trips and all nine localization entries passed.
- Documentation links, shell syntax, and nightly YAML/shell blocks passed.

App invocation (the `TEST_RUNNER_` variables apply only to this test host):

```sh
TEST_RUNNER_CORTA_STAGE_DIR=/tmp/corta-issues-stage \
TEST_RUNNER_SHELL=/bin/sh TEST_RUNNER_CORTA_RESTORE_WINDOWS=0 \
xcodebuild test -project Corta.xcodeproj -scheme Corta \
  -destination 'platform=macOS' -skip-testing:CortaUITests \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual \
  CODE_SIGNING_REQUIRED=NO DEVELOPMENT_TEAM= \
  -derivedDataPath /tmp/corta-issues-build \
  -resultBundlePath /tmp/corta-issues-final.xcresult
```

The stage config disables restore, global hotkeys, secure input and the
Applications-folder prompt. It does not change the user's configuration.
An initial run against the user shell hit a timing-sensitive
`SearchDebounceTests.caseSensitivityIsIsolatedPerPane` assertion; both
subsequent full runs using the isolated `/bin/sh` host passed.

Compiler diagnostics seen during the full build include the existing
`RemoteEditTests.swift` use of deprecated `String(contentsOf:)`; the other
existing warnings concerned the weak capture in `SFTPBrowserModel.swift`
and a non-Sendable completion in `QuickTerminalController.swift`. The final
incremental build emitted no compiler warnings. These diagnostics were
observed with the stable toolchain.

## Launched application

The Debug app was launched with the isolated developer script:

```sh
CORTA_BUILD_DIR=/tmp/corta-issues-build ./scripts/build-and-run.sh --verify
```

- **Vim:** `vim -Nu NONE -n -c 'set mouse=a ttymouse=sgr' -c split`
  on an 80-line temporary text file. Dragging text entered Vim's Visual
  mode and highlighted four lines. Dragging its horizontal divider changed
  the top pane from 14 visible text rows to 19. The first-use override hint
  was visible in the pane.
- **htop:** wheel events scrolled the process list; a drag changed the
  highlighted process row. No terminal-local selection appeared. This
  verifies the enabled event path, not an assertion that every htop build
  requests or implements drag-to-scroll.
- **tmux:** an isolated `-L corta-issue88 -f /dev/null` server with
  `mouse on` and two panes. Dragging its vertical divider moved it from
  approximately column 60 to column 80.
- Text was upright and filled the window; the alternate-screen programs
  occupied all 30 rows. Clicking and paste reached the focused terminal.

**Manual acceptance confirmed by the maintainer (2026-09-19):** plain
mouse dragging enters Vim's Visual mode; Escape exits it; holding Option
while dragging selects Corta's terminal text rather than entering Vim's
Visual mode; pasting into a text editor yields the selected text. All three
checks passed. This closes the previously outstanding physical-gesture and
clipboard verification for #88.

The full conformance checklist (including restored windows and IME) was
not repeated for these changes.

## Issue disposition

- **#89:** shared mapping and regression checks complete. Viewport offsets
  and relative rows now use one nonnegative-growth calculation, and the
  selection-copy path delegates both endpoints to the shared row mapping.
- **#88:** implementation, automated tests, real-program checks and
  maintainer-confirmed modifier-drag/clipboard verification complete.
- **#90:** cancelled by the maintainer. Corta supports released Xcode
  toolchains only; the additional channel, its CI lane and recording script
  have been removed. No further toolchain installation or verification is
  required for this issue.
