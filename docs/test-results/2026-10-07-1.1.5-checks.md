# 1.1.5 release checks

Date: 2026-10-07. Cut from `main` at `c9432a9` (#257). Marketing and core
version 1.1.5; the Release workflow sets the build counter past the feed's
6. The tree is the 1.2.0 milestone's work (#119–#126, #238), the terminal
feedback and recovery work (#213, #228), the 2026-10-06/07 review and
reliability fixes (#244–#255) and the two resize fixes found the day of
the cut (#256, #257). The version number is the maintainer's choice; the release
workflow keeps a chosen higher version rather than bumping 1.1.1 to 1.1.2.

## Automated

- Terminal core: `swift test --package-path CortaTerminal` passed — 725
  tests in 73 suites, plus the 109-, 22- and 6-test runs of the other
  targets.

  One run of the documentation commit failed `AppIntentTests`' "a tracked

## The resize fixes

#256 (the scroll region kept its old bottom margin after a window grew) was
found from a user's screenshot of Claude Code. Claude Code 2.1.292's output
was recorded under a pty while it was resized in twelve steps from 80×24 to
152×48, and replayed through the core: before the fix its input box and
status lines stacked on the old last row; after it, the grid matches the
same bytes fed to a terminal created at 152×48, both after the drag and
after a later incremental update. #257 (the cursor's column through a
reflow) has five core tests that fail without it.

## Launched application

Built from `c9432a9` with `script/build_and_run.sh --verify` and handed to
the user, who checked both fixes by resizing a CortaDev window — Claude
Code while dragging the window larger, and a shell prompt while widening
and narrowing — and confirmed them before asking for this release. The
§4.4 five-point check and the other gesture, locale and restore scenarios
were not re-run for this cut.
