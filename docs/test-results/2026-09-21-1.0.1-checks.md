## Launched-app check (§4.4, points 1–5)

Debug build launched through `scripts/build-and-run.sh` — its own staged
config under `CORTA_STAGE_DIR`, `CORTA_RESTORE_WINDOWS=0`, `SHELL=/bin/sh`;
nothing on the machine changed. The staged config added a theme whose only
override is the cursor colour:

```ini
theme = redcursor
theme.redcursor.inherit = corta
theme.redcursor.dark.cursor = #ff2020
theme.redcursor.light.cursor = #ff2020
```

| # | Check | Result |

| 6 | Restored tabbed window | **Not re-run** — nothing in tab or restore code changed |
| 7 | Non-English menu bar | **Not re-run** — no localisation change |

One thing the check turned up that is not a Corta finding: `osascript`
`keystroke` goes through the active input source, and under Pinyin the
letters were composed into candidates before reaching the terminal.
`RemoteWorkflowUITests` already switches to ABC for its own duration for
exactly this reason; a manual check has to do the same or type by hand.
