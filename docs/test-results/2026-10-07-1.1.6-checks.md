# 1.1.6 release checks

Date: 2026-10-07. A patch on 1.1.5 with one change: rounded box corners
(`╭ ╮ ╰ ╯`, U+256D–2570) are drawn as geometry joined to the grid-drawn
borders instead of from the font (#264). The user found the broken corners
in a 1.1.5 promotional screenshot of a rounded table. The release workflow
sets the version and build counter.

## Automated

- `BlockElementRenderTests.roundedCornersJoinTheirSides` renders a rounded
  box at 12, 14, 17 and 40 pt, each at scale 1 and 2, and flood-fills the
  ink from the top side: it must reach the left, right and bottom sides,
  with each cell's outer corner bare. Against 1.1.5's renderer it failed in
  all eight combinations; with the fix it passes.
  `roundedCornerPiecesStayInTheirCell` keeps every corner's rectangles
  inside the cell and its inline storage, from a 2×4 cell to 115×230 at 3×.
- App Unit plan: 919 tests in 143 suites passed, 4 known issues.
- esctest2 was not re-run: the change is in the renderer, not in
  escape-sequence handling. 1.1.5's run (131 / 334 / 102) stands.

## Frame CPU (D17)

The benchmark grid has no box-drawing characters, and the renderer checks
the U+2500–257F range before it reaches this code. Release A/B, alternating
on the same machine (Apple M5, macOS 27.0.1, Xcode 27.0, on battery):

| Build | Frame CPU avg | Full rebuild p50, CPU only |
| --- | --- | --- |
| 1.1.5 renderer | 0.754 / 0.817 ms | 0.147 / 0.151 ms |
| with #264 | 0.820 / 0.850 ms | 0.152 / 0.121 ms |

The two overlap; no change from the fix is detectable. Both are above the
1.1.5 release run's figures because the machine was busier; the unchanged
renderer measured as high.

## Launched application

A CortaDev built from the fix branch, launched with a scratch
`CORTA_STAGE_DIR` and `ZDOTDIR`, printed a rounded table: all four corners
join their sides, and lone corner characters draw as single arcs. The
§4.4 five-point check was not re-run for this patch.
