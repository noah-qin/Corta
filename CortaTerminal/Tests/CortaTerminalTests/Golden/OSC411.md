# OSC #411 interoperability captures

Generated on 2026-10-25; these contain terminal output, not third-party source.

- `osc411-imgcat-legacy.bin` and `osc411-imgcat-multipart.bin`: official
  [imgcat](https://iterm2.com/utilities/imgcat), `-l` and default respectively,
  displaying a generated one-pixel PNG.
- `osc411-imgcat-gif.bin`: the same script displaying a generated two-frame
  4×3 red/green GIF. The app decoder test independently verifies red frame zero.
- `osc411-vscode-zsh.bin`: official [VS Code zsh shell integration](https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-rc.zsh)
  in `/bin/zsh -d -i`, with a temporary ZDOTDIR and no user startup files,
  running `printf 'osc411-ok\\n'` in `/private/tmp`. Prompt, command text,
  output, exit status and cwd are compared with native OSC 133/7 processing.
